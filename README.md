# Deep Learning Practicals

This repository contains practical implementations and solutions for deep learning concepts using TensorFlow and Keras.

---

## 📂 Repository Structure

| Folder | Topic / Description | Framework & Key Libraries |
| :--- | :--- | :--- |
| **[Practical 1](./Practical%201)** | **Deep Learning Foundations**<br>Introduction to TensorFlow and Keras tensor operations and basic building blocks. | TensorFlow, Keras |
| **[Practical 2](./Practical%202)** | **Feedforward Neural Network (ANN)**<br>Digit classification on the MNIST dataset using Multi-Layer Perceptron trained with Stochastic Gradient Descent (SGD). | TensorFlow, Keras, Matplotlib |
| **[Practical 3](./Practical%203)** | **Convolutional Neural Networks (CNN)**<br>Object classification on CIFAR-10 with Conv2D, MaxPooling, Dropout, and Data Augmentation. | TensorFlow, Keras, NumPy, Matplotlib |
| **[Practical 4](./Practical%204)** | **Autoencoders**<br>Image reconstruction and dimensionality reduction on Fashion MNIST dataset using an Autoencoder architecture. | TensorFlow, Keras, NumPy, Matplotlib |
| **[Practical 5](./Practical%205)** | **Word Embeddings (Word2Vec / CBOW)**<br>Text tokenization, sequence padding, and training Continuous Bag of Words (CBOW) architecture for word representations. | TensorFlow, Keras, NumPy |
| **[Practical 6](./Practical%206)** | **Transfer Learning with Pre-trained Models**<br>Fine-tuning and feature extraction using pre-trained VGG16 model with frozen base layers on image classification benchmarks. | TensorFlow, Keras (VGG16), Matplotlib |

## 🚀 Getting Started

### Prerequisites

Ensure you have Python 3.9+ installed along with the required libraries:

```bash
pip install tensorflow keras numpy matplotlib
```

### Running a Practical

Navigate to any practical directory and run the Python script:

```bash
# Example: Run Practical 1
cd "Practical 1"
python practical_1.py
```

Outputs, evaluation metrics, and visualization graphs are saved in each practical's respective `OutPut` directory where applicable.
